Métricas por Modelo

Entendendo os Modelos de IA
1
Isolation Forest — Algoritmo de detecção de anomalias. Isola pontos "estranhos" nos dados. Funciona bem para identificar acessos que fogem completamente do padrão (ex: login de um país novo, horário nunca visto). Peso no ensemble: 40%
2
Random Forest — Algoritmo de classificação supervisionada baseado em múltiplas árvores de decisão. Classifica o acesso como legítimo ou suspeito com base em features como horário, localização, dispositivo. Peso no ensemble: 30%
3
Deep Learning — Rede neural que captura padrões mais complexos e não-lineares no comportamento do usuário (sequências de navegação, combinações sutis de features). Peso no ensemble: 30%
Resultado Final — Ensemble (média ponderada)
scoreEnsemble = (IsolationForest × 0.4) + (RandomForest × 0.3) + (DeepLearning × 0.3)

O score ensemble é ajustado pelo Trust Score (confiança histórica) do usuário, e então classificado:

Como Ler o Gráfico

Cada modelo forma um polígono colorido. Quanto maior a área, melhor o desempenho geral. Os 5 eixos medem:

Precisão Dos acessos classificados como suspeitos, quantos realmente eram. Evita alarmes falsos.
Recall Dos acessos realmente suspeitos, quantos o modelo detectou. Evita deixar passar.
F1-Score Média harmônica entre Precisão e Recall. Representa o equilíbrio entre os dois.
Consistência Baseado na % de concordância entre os 3 modelos. Quanto mais concordam, mais consistente.
Velocidade Tempo de processamento do modelo. Todos operam em milissegundos.
Se um polígono está "achatado" em algum eixo, o modelo é fraco naquele aspecto. O Ensemble combina os três para compensar as fraquezas individuais.

Como a Concordância é Calculada?

A concordância compara as classificações dos 3 modelos entre si (Isolation Forest, Random Forest e Deep Learning), sem usar nenhum como referência. Cada score é classificado individualmente:

Score ≤ 0.3 → ESPERADO  |  Score ≤ 0.7 → SUSPEITO  |  Score > 0.7 → ANÔMALO

Se os 3 modelos concordam na mesma classificação → Acordo. Se qualquer um diverge → Desacordo.

Por que o Ensemble é Superior?

O Ensemble combina os 3 modelos com pesos diferentes, reduzindo falsos positivos e negativos. Quando um modelo erra, os outros dois compensam. O Ensemble não participa do cálculo de concordância — ele é a decisão final ponderada.

Ensemble = (IF × 0.4) + (RF × 0.3) + (DL × 0.3)

Nas métricas (precisão, recall, F1), o Ensemble é usado como ground truth para avaliar cada modelo individualmente.
