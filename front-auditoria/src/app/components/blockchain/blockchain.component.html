Verifique se uma transação registrada na blockchain não foi alterada. O sistema recalcula o hash e compara com o armazenado.

Como a Verificação Funciona

1
Dados Originais
Os dados do evento (usuário, IP, risco, decisão, timestamp) são concatenados
2
Hash SHA-256
Um hash criptográfico é calculado sobre os dados concatenados
3
Comparação
O hash recalculado é comparado com o hash armazenado na blockchain
4
Resultado
Se os hashes coincidem, a integridade está garantida. Qualquer alteração nos dados modifica o hash
A propriedade fundamental da blockchain é que alterar qualquer dado em um bloco invalida todos os blocos subsequentes, tornando adulterações facilmente detectáveis.
